# @suigar/sdk

This package ships only a pointer to the full Suigar skills, which live on GitHub to keep the npm package small.

## Read the full skill

Fetch the full skill from `main`:

```
https://raw.githubusercontent.com/Suigar-Gaming/agent-skills/main/skills/installation/SKILL.md
```

Read it completely before writing Suigar SDK integration code. Its links to `references/*.md` are relative to that URL, so fetch them from:

```
https://raw.githubusercontent.com/Suigar-Gaming/agent-skills/main/skills/installation/references/<file>.md
```

Follow links to other skills when needed, resolving them relative to the fetched document URL. Always use `main` for skills and references.

To browse the skill: https://github.com/Suigar-Gaming/agent-skills/tree/main/skills/installation
